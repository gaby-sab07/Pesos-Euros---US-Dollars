# Pesos-Euros-->US-Dollars
This is C++ code that converts Mexican Pesos and euros to U.S. Dollars. You can run it by copying and pasting it into an online C++ compiler like GDB or Programiz, then running it. Then answer the prompts for the amount of pesos and euros while it does the conversion. This code helped me understand how to effectively use static_cast and the modulo (%) operator correctly.
